# space-shooter
A 2D space shooter game developed using Godot.

 Features

- Player movement
- Laser shooting
- Shooting cooldown
- Meteor spawning
- Meteor destruction
- Player health system
- Heart-based health UI
- Score system
- Game over screen

#Controls

 W,↑ - Move up 
 A,← - Move left 
 S,↓ - Move down 
 D,→ - Move right 
 Space - Shoot
